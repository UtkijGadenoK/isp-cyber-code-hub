MODULE 01 • CHEAT SHEET CARD

Data Output Mechanisms

Visual Reference for Output Channels, String Rules & Variable Conventions

📡 Output Channels

CARD 01
console.log() --> Developer Console (Hidden/Debug)
alert() --> Pop-up Window (Pauses Screen)
document.write() --> Web Page Body (Renders HTML)
// 1. Developer Console
console.log("Testing code...");

// 2. Pop-up Window
alert("Welcome to ISP!");

// 3. Web Page HTML
document.write("<h1>Hello World</h1>");

🔤 String Creation & Backticks

CARD 02
Quote Type Multi-line? Variables ${}?
Double " ❌ No ❌ No
Single ' ❌ No ❌ No
Backticks ` ✅ YES ✅ YES
let studentName = "Lucy";
document.write(`Name: <strong>${studentName}</strong>`);

🏷️ Variable Rules & camelCase

CARD 03
let userName = "Alex"; // camelCase standard

❌ Forbidden: let 1user (number at start) | let user name (space) | let user-name (hyphen)

🔢 Auto-Increment Counters

CARD 04
let index = 0;
index++; // Shorthand for index = index + 1!
document.write(`<p>${index}. First Item</p>`);
