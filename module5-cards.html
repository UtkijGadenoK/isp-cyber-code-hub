📦 1. Code Blocks & Scope

CARD 01

Declaring duplicate variable names in the same scope causes a SyntaxError. Curly braces {} create an isolated sandbox where local variables live only inside that block.

Global Scope --> Outer Variables (Visible everywhere)
{ Block Scope } --> Curly Braces Sandbox (Local Variables)
ReferenceError --> Outer code CANNOT see inside { }
let hero = "Tony"; // Global

{
   let armor = "Mark 85"; // Local to block
console.log(hero, armor); // ✅ "Tony" "Mark 85"
}

// console.log(armor); ❌ ReferenceError!
💡 Scope Rule: Blocks allow reusing common variable names like age without collision errors.

⚙️ 2.Function Declaration & Call

CARD 02
Step Syntax Action
1. Declaration function name() { } Writes the recipe (Waits)
2. Invocation name(); Bakes the cake (Executes)
let index = 0;

// 1. Declaration
function launchAlert() {
  index++;
  console. log(`Mission #${index} ready!`);
}

// 2. Calling 3 times:
launchAlert(); //"Mission #1 ready!"
launchAlert(); //"Mission #2 ready!"
⚠️ Watch Out: Writing launchAlert without () does NOT run the function!

🎯 3. Parameters vs. Arguments

CARD 03
Parameter --> Placeholder variable: (name, age)
Argument --> Concrete value passed: ("Thor", 1500)
// userName & heroAge are Parameters
function showHero(userName, heroAge) {
  document.write(`<p>${userName}: ${heroAge} yrs</p>`);
}

// Static Arguments:
showHero("Thor", 1500);

// Dynamic via prompt() & Number():
showHero(prompt("Name:"), Number(prompt("Age:")));
💡 Type Reminder: Always wrap numerical prompts in Number() to avoid string concatenation.

📊 4. Roster & Group Accumulators

CARD 04
let totalAge = 0;
let count = 0;

function addMember( name, birthYear) {
  let age = 2026 - birthYear;
  totalAge += age; // Accumulate
  count++;
  document.write( `<li>${count}. ${name} (${age} yrs)</li>`);
}

addMember("Tony", 1970);
addMember("Steve", 1918);

document.write(`Avg: ${(totalAge / count).toFixed(1)}`);
🚀 DRY Principle: "Don't Repeat Yourself" — Write your HTML card once inside the function!
