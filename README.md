# 🌌 ISP Cyber Code Hub — Web Development Course Portal

An interactive, cyber-neon educational web portal built for **International School Phuket (ISP)** frontend programming curriculum.

## 🚀 Features

- **Cyber-Neon Aesthetic:** Dark glassmorphism cards, glowing cyan/magenta accents, and responsive layout.
- **Featured Security Terminal:** Interactive PIN access control system with simulated biometric scanner laser, Web Audio API sound synthesis, emergency alert states, and auto-reset loop.
- **Course Curriculum Modules:** Covers JavaScript output methods (`console.log`, `alert`, `document.write`), variables & template literals, `prompt()`/`confirm()` user inputs, type casting (`Number()`), and auto-increment logic.
- **ISP Eco Houses Showcase:** Highlights the four school houses: **Green Guardians 🛡️**, **Water Protectors 🌊**, **Sun Keepers ☀️**, and **Forest Rangers 🦋**.

## 🌐 Deploying to GitHub Pages

1. Create a new repository on GitHub named `isp-cyber-code-hub`.
2. Push or upload these files (`index.html`, `style.css`, `main.js`, and images) to your repository.
3. Go to **Settings → Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your website will be live worldwide at `https://<your-username>.github.io/isp-cyber-code-hub/`!
